## Month 1 Journey and Learnings

### JS/TS Fundamentals

My opening gate to the programming world before reaching the Blockchain hellgate. Please be informed I’m only taking the backend path for now.

For JavaScript, I’m using the freeCodeCamp modules. Concepts I’ve learned: Variables and Strings, Booleans and Numbers, Functions, Arrays, Objects, Loops, Higher-Order Functions and Callbacks, Debugging, Maps and Sets, Classes, Data Structures, Functional Programming, and Async.

For TypeScript, I’m using Codecademy. Concepts I’ve learned: Basic types, Interfaces, Type aliases, Optional properties, Literal types, Union types, Intersection types, Enums, Type assertions, Utility types, Discriminated unions, Error handling, Type guards, Classes and object-oriented programming.

### SQL Fundamentals

I used SQL Bolt to learn SQL. This is for extracting, querying, indexing data, and communicating with databases. I didn’t deep dive too far considering this will be a complementary skill to elevate my backend engineering. Concepts I’ve learned: SELECT, FILTER, querying, JOIN, WHERE, indexing, and altering. More to come as I progress onwards.

### Node.js & Express.js

The runtime environment and framework for my path. I don’t think there’s much heavy theory here. It’s more about how machines talk to each other (cmiiw). Rather than focusing on theory, these two are better learned through applied practices. So far, I know how to create a database, export, and import using them and a terminal. Fun.

## Progression Summary & Opinions

JS/TS has been a relaxing journey. JavaScript is more flexible. I can code however I want, tinker, and alternate the logic. TypeScript, on the other hand, is strict, but I like it more. It feels like the code has a rigid foundation before I code forward, though it does give me a headache. One concept that’s killing me is async. That’s where I stumbled and halted my progression towards DrizzleORM. It feels like it needs weeks to understand fundamentally. For async itself, I’ll keep working on it for months onward to build better understanding and get it into muscle memory.
